# Prototype 3 Research Claim Boundary

## Main Supported Claim

Prototype 3 supports the claim that local model task-planning behaviour can be evaluated systematically using a fixed benchmark and separated validity metrics.

## Strong Claims Supported

- Benchmark runner can generate repeatable local evaluation evidence.
- Model response success differs from JSON validity.
- JSON validity differs from schema validity.
- Schema validity differs from safety/execution eligibility.
- Results can be exported for later analysis and dissertation evidence.

## Claims Not Supported

- Local inference is better than cloud inference.
- Local models are safe robot controllers.
- Physical robot deployment is validated.
- 30 commands prove general language understanding.
- Quantisation improves performance.
- Resource efficiency is measured.

## Wording to Avoid

- "Prototype 3 proves the model is accurate."
- "Prototype 3 proves safe robot control."
- "Prototype 3 completes the Microsoft brief alone."
- "Prototype 3 demonstrates production deployment."

## Examiner-Safe Wording

Prototype 3 provides controlled benchmark evidence for local model structured-output behaviour. Its claims are bounded to the benchmark, model configuration and validation pipeline used.
